# Contributing

Keep changes focused, documented and buildable for `esp8266:esp8266:d1_mini`.

1. Never commit `secrets.h`, credentials, IP addresses, GPS-tagged photos or
   live logs.
2. Run `scripts/build.ps1` and `tests/run-static-checks.ps1` before a pull
   request.
3. Update the relevant reference document when behaviour or tested hardware
   changes.
4. For hardware reports, name the KLI revision and separate an ESP contact
   pulse from observed shutter movement.
